## 六、重複執行驗收

在專案根目錄執行：

```bash
node smart-factory-command-center/08_測試與驗收/智慧5S_正式驗收.js
```

無網路時只驗收本機封版檔案：

```bash
node smart-factory-command-center/08_測試與驗收/智慧5S_正式驗收.js --略過線上
```

驗收程式只讀取檔案與正式 GAS，不會新增、修改或刪除任何試算表資料。

正式寫入閉環需明確加上 `--執行`，未加參數時會安全停止：

```bash
node smart-factory-command-center/08_測試與驗收/智慧5S_正式寫入驗收.js --執行
```

此命令會在正式中央資料庫建立可追溯的驗收資料，不應作為一般日常檢查重複執行。
