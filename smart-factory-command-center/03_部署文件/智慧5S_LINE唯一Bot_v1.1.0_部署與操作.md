## 二、v1.1.0 新增內容

1. 群組內可直接輸入指令，自動讀取 Webhook 的真實 LINE 群組識別碼。
2. 只有已完成 LINE 身分綁定，且具主管、班長、工程師或更高權限者可以設定。
3. 綁定前呼叫 LINE 群組摘要 API，確認既有 Bot 確實位於該群組。
4. 已綁定其他群組時拒絕普通覆蓋，必須使用「改綁確認」。
5. 解除綁定必須使用「解除確認」，且只能解除目前群組擁有的區域。
6. 自動建立 `5S_LINE群組綁定紀錄`，保存操作者、區域、群組與異動結果。
7. 通知自動加入通知編號與智慧 5S PWA 入口。
8. 依 `去重鍵` 阻止已發送案件再次推播。
9. 所有啟用區域未完成群組設定時，拒絕建立每小時觸發器。
10. 偵測到主 GAS 的 `智慧5S_發送待通知自動化` 觸發器時，拒絕建立第二條通知路徑。
11. 受控測試必須輸入固定確認文字，避免管理員誤觸推播。


Git 已同步三份現行路由來源：

## 四、雲端發布順序

1. 先確認既有 `LINE_CHANNEL_ACCESS_TOKEN` Script Property 存在；不得讀出、複製或寫入 Git。
2. 新增或覆蓋上述兩個 v1.1.0 模組。
3. 將 5S 群組處理器接到實際生效的 `doPost(e)` 第一順位。
4. 儲存專案。
5. 執行 `測試_智慧5S_LINE群組綁定_解析指令()`，結果必須為 `成功: true`。
6. 執行 `測試_智慧5S_LINE橋接_通知內容與發送結果()`，結果必須為 `成功: true`。
7. 執行 `智慧5S_LINE橋接_健康檢查()`；此時四區尚未綁群組可顯示不可正式啟用，屬正常保護。
8. 更新既有 Web App 部署為新版本，保留原部署與 Webhook URL，不新增第二個 Webhook。
9. 到 LINE Developers 確認 Webhook 使用中，並已允許 Bot 加入群組。

## 五、現場第一次啟用

第一階段建議四區共用一個正式群組：`A9 智慧5S示範區`。

1. 由 LINE 群組管理員建立或指定正式群組。
2. 將既有 NEXUS OS LINE Bot 邀請進群組。
3. 操作者先在 Bot 一對一聊天室輸入：

```text
綁定 你的工號
```

4. 回到正式群組輸入：

```text
5S群組說明
```

5. 查詢目前四區狀態：

```text
5S群組狀態
```

6. 四個啟用區域共用目前群組：

```text
5S群組綁定 全部
```

7. 再次輸入 `5S群組狀態`，四區都應顯示「已綁定本群組」。
8. 到中央資料庫確認 `5S_區域主檔.LINE群組識別碼` 四列已寫入，並確認 `5S_LINE群組綁定紀錄` 有四筆完成紀錄。

## 六、改綁與解除

普通綁定發現其他群組時只會提示，不會覆蓋。經區域主管與 LINE 管理員確認後才輸入：

```text
5S群組改綁確認 區域代碼
```

四區全部改綁：

```text
5S群組改綁確認 全部
```

解除目前群組的一個區域：

```text
5S群組解除確認 區域代碼
```

解除目前群組擁有的全部區域：

```text
5S群組解除確認 全部
```

解除指令不會動到已屬於其他群組的區域。

## 七、受控推播測試

先執行唯讀預覽：

```javascript
智慧5S_LINE橋接_預覽待通知(5)
```

確認區域與群組正確後，執行一筆受控實際測試：

```javascript
智慧5S_LINE橋接_發送區域測試('A9-1069檢驗桌', '確認發送測試')
```

驗收標準：

- 正式群組只收到一則測試通知。
- 通知包含區域名稱、通知編號與智慧 5S PWA 入口。
- `5S_通知紀錄` 對應測試列狀態為「已發送」。
- 非正式群組沒有收到訊息。
- 若發送中斷，測試列不會由排程自動重送。

## 八、建立正式排程

測試通過後執行：

```javascript
智慧5S_LINE橋接_建立每小時觸發器()
```

函式會先確認：

- 既有 Bot 權杖已設定。
- 既有 `發送LINE通知()` 可用。
- 中央區域與通知分頁可用。
- 每個啟用區域都有群組識別碼。
- 每個正式收件群組都已有一筆成功的受控群組測試紀錄。
- 沒有 `智慧5S_發送待通知自動化` 衝突觸發器。

禁止在主 5S GAS 專案執行 `智慧5S_建立每日觸發器_()`，因該函式會同時建立主 GAS 直接通知路徑，可能造成重複推播。每日統計只保留 `智慧5S_每日自動化`；LINE 通知只保留既有 NEXUS OS 專案的 `智慧5S_LINE橋接_每小時`。

## 九、緊急停止與復原

發現錯群組、重複通知或大量異常時，立即執行：

```javascript
智慧5S_LINE橋接_停止每小時觸發器()
```

保留 `5S_通知紀錄` 與 `5S_LINE群組綁定紀錄`，不要批次改成已發送。修正後依序執行健康檢查、唯讀預覽、單筆受控測試，再恢復每小時排程。
