## 二、已完成的現場功能

1. 以既有 `01_人員主檔` 工號或姓名登入。
2. 依職稱自動判斷：主管、區域負責人、現場人員。
3. 選擇示範區後執行 5S 行動巡檢。
4. 評分標準：5 分符合、3 分輕微偏差、1 分異常、0 分重大異常。
5. 低於 5 分強制填寫原因並拍照。
6. 巡檢異常自動建立改善單與改善歷程。
7. 重大異常自動寫入 `5S_通知紀錄`，狀態為「待發送」。
8. 改善流程：待改善 → 改善中 → 驗證中 → 已結案；主管可駁回。
9. 改善完成必須拍攝改善後照片。
10. 物品盤點依每日、每週、每月、很少使用、用不到分類。
11. 非必要品自動建立紅牌、30 天期限與連動改善單。
12. 紅牌可開始處理並由主管或區域負責人結案。
13. 戰情首頁顯示今日巡檢、平均分、未結改善、逾期與紅牌。
14. 支援 PWA 安裝、Service Worker、離線啟動與 IndexedDB 待同步佇列。

## 五、現場驗收步驟

1. 以人員主檔中的工號登入。
2. 選「巡檢」→「A9 1069 檢驗桌」。
3. 任一項選 3、1 或 0 分，確認系統要求原因與照片。
4. 完成全部項目並送出。
5. 確認 `5S_巡檢主檔` 新增一筆。
6. 確認 `5S_巡檢明細` 依項目數新增資料。
7. 確認異常項目在 `5S_改善單` 自動建立案件。
8. 到「改善」開始改善、拍改善後照片並送驗。
9. 以主管或區域負責人登入完成驗證結案。
10. 關閉 Wi-Fi 後再巡檢一次，確認顯示離線且資料進入待同步。
11. 恢復網路，到「設定」按立即同步，確認資料補寫成功。
12. 到「紅牌」新增一筆非必要品，確認紅牌與改善單同步建立。

## 六、LINE 自動通知啟用

PWA 已會把重大巡檢異常與新紅牌寫入 `5S_通知紀錄`。

要真正推播至 LINE 群組，需把：

```text
smart-factory-command-center/01_GAS後端/智慧5S管理平台_完整後端.gs
```

加入目前 Apps Script 專案，並在主 `doPost` 的模組路由陣列加入：

```javascript
'智慧5S_嘗試處理動作_'
```

接著設定指令碼屬性：

```text
LINE_CHANNEL_ACCESS_TOKEN
智慧製造_SPREADSHEET_ID
```

各區域的 LINE 群組識別碼填入 `5S_區域主檔` 的 `LINE群組識別碼` 欄位，最後執行一次：

```javascript
智慧5S_建立每日觸發器_()
```

會建立：

- 每日 17:10 區域統計與排名快照。
- 每小時處理一次待發送 LINE 通知。

## 七、照片儲存說明

目前可直接使用的版本，會把手機照片壓縮到約 42,000 字元以下，寫入中央試算表，讓離線排隊與現場測試可立即運作。

進階後端已提供 `智慧5S_儲存照片_`，之後可將照片改存 Google Drive，試算表只保留縮圖網址，以降低資料庫容量。
