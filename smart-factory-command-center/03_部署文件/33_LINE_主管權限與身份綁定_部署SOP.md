## 一、模組定位

第 33 階段只處理 LINE 身份綁定與權限控管，不改 Rich Menu 圖片，不改 PWA，不進入排程。

目的：

- 誰可以看主管戰情。
- 誰可以查今日戰情 / 昨日戰情。
- 誰可以查主檔檢查。
- 誰可以看 AI摘要。
- 現場人員保持可報工。

1. 完整覆蓋 Apps Script 內的 `33_LINE_主管權限與身份綁定.gs`。

3. 執行：

```javascript

```

4. 執行：

```javascript

```

5. 驗收結果必須為 `成功: true`，並顯示黃嘉欣為工程師、權限等級 60。
