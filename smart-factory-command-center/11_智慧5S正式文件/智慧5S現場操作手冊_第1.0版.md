## 二、登入與身分核對

### 2.1 正式登入

1. 第一次登入前確認裝置在線。
2. 在「工號或姓名」輸入完整工號；必要時可輸入完整姓名。
3. 點「登入智慧 5S」。
4. 等待人員資料與區域資料載入完成，不連續重按登入。
5. 進入首頁後核對姓名、角色與部門。

| 畫面位置 | 應看到的內容 | 現場判定 |
|---|---|---|
| 登入頁標題 | 化新精密｜智慧 5S | 不是此標題時停止登入 |
| 版本資訊 | 第 1.0.2 版 | 版本不同時通知管理員 |
| 首頁稱呼 | 本人姓名 | 他人姓名立即登出 |
| 設定頁資料 | 本人工號、部門、組別、職稱與角色 | 任一不符都先停止正式寫入 |

### 2.2 登入問題怎麼處理

| 畫面訊息 | 代表情況 | 現場處理 |
|---|---|---|
| 請輸入工號或姓名 | 欄位未填 | 輸入完整資料後再登入 |
| 人員主檔找不到此工號或姓名 | 未找到啟用人員或資料載入異常 | 截圖並記錄輸入值、時間與裝置 |
| 此人員目前已停用 | 人員主檔為停用 | 請主管確認，不借用他人工號 |
| 核心資料載入失敗 | 區域或檢查項目未成功讀取 | 確認網路後更新；仍失敗即回報 |
| 目前沒有網路 | 裝置離線 | 首次登入改為連網；不得猜測身分 |

### 2.3 公用裝置交接

1. 接班者先確認畫面不是前一位使用者。
2. 前一位使用者先到「設定」確認待同步 0。
3. 前一位點「登出」，直到畫面回到登入頁。
4. 接班者用自己的工號登入。
5. 不得用清除瀏覽器資料代替正常登出與同步。

> 身分不正確比無法登入更危險。看見他人姓名時，不得繼續巡檢、改善或紅牌作業。

## 三、開始巡檢前

### 3.1 進入巡檢

1. 從首頁點「立即開始巡檢」，或點底部「巡檢」。
2. 選擇實際所在且由自己負責的巡檢區域。
3. 核對區域名稱、樓層、責任人與檢查項目。
4. 確認現場可安全接近後再開始評分。

| 巡檢前檢查 | 正確做法 | 錯誤做法 |
|---|---|---|
| 區域 | 站在現場核對區域名稱 | 在辦公室憑印象選區 |
| 人員 | 本人登入並自行判定 | 共用他人帳號或代填 |
| 現況 | 先看現況再評分 | 先整理後才拍照評分 |
| 基準 | 依畫面檢查項目逐一確認 | 只看整體整齊就給分 |
| 安全 | 有立即風險先停止與通報 | 為了完成巡檢繼續冒險 |

### 3.2 逐項檢查原則

- 每一個檢查項目都必須評分。
- 評分以當下事實為準，不以昨日印象或預期改善結果代替。
- 同一問題影響多個項目時，各項仍依實際符合程度判定。
- 發現低於 5 分的項目，先保留現況證據再處理。
- 不確定評分時，先讀畫面檢查基準，再請區域負責人確認。

### 3.3 巡檢畫面辨識

| 畫面區塊 | 用途 | 操作提醒 |
|---|---|---|
| 區域選擇 | 指定本次巡檢區域 | 選錯區域不要送出 |
| 檢查項目卡 | 顯示分類、項目與基準 | 逐卡完成，不跳項 |
| 分數按鈕 | 選擇 5、3、1 或 0 分 | 只選一個最符合現況的分數 |
| 異常原因 | 說明低於 5 分的事實 | 寫位置、物件、數量與影響 |
| 現況照片 | 留下可定位的異常證據 | 清楚、對焦、能辨識區域 |
| 整體備註（選填） | 補充跨項或交接事項 | 不用來取代異常原因 |

## 四、評分、原因與照片

### 4.1 四級評分

| 分數 | 現場意義 | 判定重點 | 後續 |
|---|---|---|---|
| 5 分 | 完全符合 | 現況與標準一致，且可維持 | 可直接進下一項 |
| 3 分 | 大致符合但有缺口 | 局部偏差、標示不足或維持性不佳 | 填原因、拍照並建立改善 |
| 1 分 | 明顯不符合 | 多處偏差、影響作業或容易再發 | 填原因、拍照並建立改善 |
| 0 分 | 嚴重不符合或有立即風險 | 標準未建立、全面失控或涉及安全品質 | 先控制風險，再填原因與拍照 |

> 所有低於 5 分的項目都必須填異常原因並附現況照片；系統會建立改善案件。

### 4.2 異常原因怎麼寫

原因至少回答四件事：在哪裡、是什麼、差多少、造成什麼影響。

| 寫法 | 範例 | 判定 |
|---|---|---|
| 完整事實 | 機台西側地面有兩處油漬，約手掌大小，行走有滑倒風險 | 可定位、可驗證 |
| 完整事實 | 量具架六個定位中有兩支未歸位，交接時無法立即確認去向 | 可計數、可追蹤 |
| 太模糊 | 很亂、要改善、不合格 | 不可驗證 |
| 只有推測 | 應該是夜班造成 | 沒有現場事實 |

### 4.3 現況照片怎麼拍

1. 先拍一張能辨識區域與物件位置的全景。
2. 再拍一張能看清異常細節的近景。
3. 畫面保持對焦、光線足夠，不用濾鏡或舊照片。
4. 避免拍到與案件無關的個人資料、螢幕內容或機密文件。
5. 拍攝後查看預覽，確認方向與內容正確。

| 合格照片 | 不合格照片 |
|---|---|
| 能看出區域、物件、異常位置與程度 | 只有局部特寫，無法判斷位置 |
| 畫面清楚、光線足夠、時間與現況一致 | 模糊、過暗、反光或使用舊照片 |
| 前後照片角度接近，方便比對 | 改善後只拍別處或避開問題點 |
| 不含無關個資與敏感內容 | 拍到人員名單、密碼或受限資料 |

### 4.4 低分項目送出前檢查

- [ ] 分數與現況一致，沒有為了好看而提高分數。
- [ ] 異常原因包含位置、物件、數量或範圍與影響。
- [ ] 現況照片能定位且清楚。
- [ ] 有立即風險時已先停止、隔離、標示與通報。
- [ ] 沒有用整體備註取代個別項目的原因與照片。

## 五、送出巡檢與確認結果

### 5.1 送出前最後核對

1. 確認區域正確。
2. 確認全部檢查項目都已評分。
3. 確認所有低於 5 分項目都有原因與照片。
4. 必要時填「整體備註（選填）」。
5. 點「送出巡檢」一次，等待處理完成。

### 5.2 送出後要看什麼

| 畫面結果 | 代表意義 | 下一步 |
|---|---|---|
| 顯示巡檢單號 | 已形成可追溯巡檢識別 | 記錄單號並確認異常案件 |
| 顯示已儲存 | 線上寫入完成 | 回到巡檢或首頁更新確認 |
| 顯示等待同步 | 工作先存於本裝置 | 記錄待同步筆數，恢復網路後補送 |
| 顯示欄位錯誤 | 必填資料不完整 | 依提示補齊後再送出 |
| 長時間沒有結果 | 網路或服務可能異常 | 不連續重按，先截圖與記錄時間 |

### 5.3 送出後三項確認

- [ ] 已看到並記下巡檢單號。
- [ ] 低分項目已形成改善案件，責任與期限可追蹤。
- [ ] 設定頁待同步為 0；若不為 0，已記錄筆數與裝置。

### 5.4 不要這樣做

| 錯誤動作 | 風險 | 正確處理 |
|---|---|---|
| 連續點「送出巡檢」 | 可能重複建立資料 | 點一次後等待；異常時先保留畫面 |
| 送出中直接關閉系統 | 無法判斷是否已建立單號 | 等待結果或記錄後再回報 |
| 看到等待同步就當作完成 | 資料尚未進入中央資料庫 | 恢復網路後立即同步並回讀 |
| 選錯區域仍繼續送出 | 形成錯區正式紀錄 | 送出前返回重選；已送出立即回報 |

## 六、處理改善案件

### 6.1 找到自己的案件

1. 點底部「改善」。
2. 進入「我的」或使用畫面篩選找到本人負責案件。
3. 點案件詳情，核對改善單號、區域、異常原因、現況照片、責任人與期限。
4. 若案件不屬於自己或資料錯誤，先通知區域負責人，不逕自結案。

| 狀態 | 代表意義 | 現場人員可做的事 |
|---|---|---|
| 待改善 | 案件已建立，尚未開始 | 確認責任後點「開始改善」 |
| 改善中 | 已接單處理 | 實作改善、拍照、填說明並送驗 |
| 驗證中 | 已送管理角色驗證 | 保持現場狀態並追蹤結果 |
| 已結案 | 驗證合格 | 維持標準；再發時建立新紀錄 |

### 6.2 開始改善

1. 到現場確認問題仍與案件一致。
2. 確認不會引入新的安全、品質或設備風險。
3. 點「開始改善」。
4. 確認狀態由「待改善」變為「改善中」。
5. 依責任與期限執行；需要資源時立即提出。

### 6.3 改善做到什麼程度

| 層次 | 作法 | 是否足以送驗 |
|---|---|---|
| 臨時控制 | 先隔離、擦拭、移開或加警示 | 只能降低風險，通常不足 |
| 恢復標準 | 回到定位、定量、標示與清潔基準 | 可作為基本送驗條件 |
| 防止再發 | 補上責任、頻率、上限、目視化或點檢 | 優先採用 |
| 標準更新 | 經核准修正區域基準或檢查方式 | 需由負責角色確認 |

> 改善不是把問題移到看不見的地方。移位、藏放、暫時擦拭或只換照片，都不等於完成。

## 七、改善回報與送驗

### 7.1 改善後照片

1. 使用與現況照片接近的角度與距離拍攝。
2. 讓照片同時看出原問題已消除、定位或標示已恢復。
3. 有防止再發措施時，把目視化、上限、責任或點檢方式拍清楚。
4. 不使用舊照片、示意照片或別區照片。

### 7.2 處理說明怎麼寫

| 必寫內容 | 完整範例 |
|---|---|
| 做了什麼 | 清除機台西側兩處油漬並完成地面清潔 |
| 原因怎麼處理 | 鎖緊接頭並更換破損油管，試運轉後無滲漏 |
| 如何防止再發 | 增加每班接頭目視檢查，責任人為當班設備操作員 |
| 如何確認 | 連續觀察三十分鐘，地面與接頭均無新油跡 |

### 7.3 完成並送驗

1. 確認實際改善已完成，不只剩臨時措施。
2. 上傳清楚的改善後照片。
3. 填寫具體處理說明。
4. 點「完成並送驗」一次。
5. 確認狀態由「改善中」變為「驗證中」。
6. 保持現場成果，等待區域負責人或主管驗證。

| 送驗前檢查 | 合格條件 |
|---|---|
| 異常 | 原問題已消除或已受核准控制 |
| 照片 | 能與現況照片前後比對 |
| 說明 | 寫出處理、原因、防再發與確認方式 |
| 現場 | 定位、標示、清潔與安全狀態正常 |
| 系統 | 顯示驗證中，待同步已確認 |

### 7.4 被駁回後

1. 讀取驗證意見與具體駁回原因。
2. 回現場確認仍不足的部分。
3. 案件回到「改善中」後補做改善。
4. 重新拍攝改善後照片並更新處理說明。
5. 再次點「完成並送驗」。

> 「完成並送驗」不是結案。只有驗證通過後，案件才會進入「已結案」。

## 八、物品盤點與紅牌

### 8.1 新增物品盤點

1. 點底部「紅牌」。
2. 點「＋ 新增物品盤點」或右下角「＋」。
3. 選擇正確區域，填寫物品名稱、數量、單位與存放位置。
4. 依實際使用頻率與工作需要判定「必要」或「非必要」。
5. 拍攝能辨識物品、數量與位置的照片。
6. 送出一次並記錄盤點編號。

| 判定 | 現場判斷 | 系統結果 |
|---|---|---|
| 必要 | 現行工作確實需要，數量與位置符合基準 | 建立盤點紀錄 |
| 非必要 | 長期未用、超量、無主、損壞、待報廢或不應留在現場 | 建立盤點紀錄並自動建立紅牌 |
| 不確定 | 用途、責任、規格或期限無法確認 | 先選擇符合現況的判定並請責任人確認，不自行丟棄 |

### 8.2 非必要品掛牌

1. 記錄系統顯示的紅牌編號。
2. 依現場規定掛上實體紅牌或可辨識標示。
3. 將物品移至指定紅牌暫存區；涉及安全、重量、化學品或品質管制時先請主管處置。
4. 暫存區保持物品、紅牌編號與系統案件一一對應。
5. 不把非必要品放回原位，也不未經核准直接報廢。

| 必留證據 | 現場要求 |
|---|---|
| 物品照片 | 可辨識品名、外觀、數量與原位置 |
| 盤點編號 | 送出後立即記錄 |
| 紅牌編號 | 非必要品必須與實體標示一致 |
| 暫存位置 | 交接者可以實際找到物品 |
| 責任與期限 | 知道由誰處理、何時到期 |

### 8.3 紅牌狀態

| 狀態 | 代表意義 | 現場動作 |
|---|---|---|
| 待處置 | 已掛牌，尚未開始處理 | 確認方式與責任後點「開始處理」 |
| 處理中 | 正在移轉、退庫、維修、報廢或申請保留 | 保留過程證據並維持暫存區秩序 |
| 已結案 | 管理角色已確認實際結果 | 實體物品、標示與系統結果一致 |

## 九、開始處理紅牌與交接

### 9.1 開始處理

1. 開啟紅牌案件詳情。
2. 核對紅牌編號、物品、數量、原位置與暫存位置。
3. 確認處置方式、責任人與需要會辦的單位。
4. 點「開始處理」。
5. 確認狀態由「待處置」變為「處理中」。

### 9.2 常見處置

| 處置方式 | 現場要點 | 不得省略 |
|---|---|---|
| 移轉 | 新位置符合需求且已更新標示 | 新位置與接收人 |
| 退庫 | 數量、料號與接收紀錄一致 | 退庫日期與憑證 |
| 維修 | 故障內容、送修單位與預計完成日清楚 | 維修紀錄與回廠確認 |
| 報廢 | 完成核准與分類處理 | 核准與實際處置證據 |
| 保留 | 有明確理由、責任人、位置與期限 | 核准人與複查日期 |

### 9.3 結案邊界

「完成並結案」只由主管或區域負責人依權限執行。現場人員完成實際處置後，應提供實際日期、結果、位置與證據，並等待管理角色確認。

| 現場已完成 | 還不能結案 |
|---|---|
| 實體物品已依核准方式處置 | 物品仍在暫存區但只口頭說會處理 |
| 數量、位置與系統案件一致 | 系統寫已報廢但物品仍在現場 |
| 必要憑證、照片或接收紀錄齊全 | 只有一張看不出物品去向的照片 |
| 暫存標示已正確移除或更新 | 實體紅牌與系統狀態不一致 |

### 9.4 跨班交接

- 交接紅牌編號與物品名稱。
- 說明目前狀態、暫存位置與已完成處置。
- 說明下一步、責任人與期限。
- 指出安全、品質或搬運限制。
- 交接人與接班人共同核對實體物品。

## 十、離線作業與立即同步

### 10.1 看到離線時

系統顯示「離線」時，允許的新增工作可先存在本裝置的待同步佇列。這只是暫存，不代表已進入中央資料庫。

| 可優先離線執行 | 建議等在線再執行 |
|---|---|
| 新增巡檢 | 改善驗證 |
| 新增物品盤點 | 紅牌結案 |
| 必要的現況照片與原因 | 主檔或權限變更 |

### 10.2 恢復網路後

1. 確認頁首顯示「在線」。
2. 點底部「設定」。
3. 查看「離線同步」的待同步筆數。
4. 待同步大於 0 時點「立即同步」一次。
5. 等待畫面顯示成功、失敗與剩餘結果。
6. 最終確認待同步為 0。
7. 點「清除快取並更新」，再以單號回讀巡檢、改善或紅牌資料。

| 同步結果 | 現場判定 | 處理 |
|---|---|---|
| 成功，剩餘 0 | 補送完成 | 回讀單號與狀態 |
| 部分成功，仍有剩餘 | 尚未完成 | 記錄成功、失敗、剩餘與錯誤訊息 |
| 待同步不減 | 可能仍離線或服務異常 | 不連續重按，截圖後回報 |
| 出現重複或錯列 | 資料一致性異常 | 立即停止操作並保留單號 |

### 10.3 離線時禁止事項

- 不清除瀏覽器資料。
- 不移除系統圖示或重新安裝。
- 不刪除待同步資料。
- 不在多台裝置重複輸入同一筆作業。
- 不把「已排隊」說成「已正式完成」。

> 班別結束前應完成同步。確實無法補送時，交接內容至少包含裝置、本人、區域、作業時間、單號、待同步筆數與畫面截圖。

## 十一、常見錯誤與停止點

### 11.1 畫面異常處理

| 問題 | 先做什麼 | 不要做什麼 |
|---|---|---|
| 無法登入 | 截圖、記錄輸入值、時間、裝置與網路 | 重複試不同他人工號 |
| 區域或項目不見 | 確認版本與網路，更新一次 | 猜測區域或改填別區 |
| 照片無法上傳 | 保留現況、檢查相機權限與網路 | 用無關照片代替 |
| 送出後沒有結果 | 等待、截圖、記錄區域與時間 | 連續重按送出 |
| 待同步不歸零 | 記錄成功、失敗、剩餘與錯誤 | 清除瀏覽器資料 |
| 狀態或資料錯列 | 停止後續更新並保留單號 | 以新增假資料掩蓋 |
| 權限按鈕不正確 | 核對本人角色並回報 | 借用主管帳號 |

### 11.2 必須立即停止並通報

- 可能造成人員受傷、產品混料、設備損壞或生產中斷。
- 畫面顯示他人身分，或案件內容與現場明顯不符。
- 同一作業出現兩個正式單號。
- 補送後出現重複資料、錯區、錯人或狀態跳轉。
- 照片含有不應保存的個人資料或機密內容。

### 11.3 異常回報六要素

| 回報項目 | 要填什麼 |
|---|---|
| 人員與時間 | 姓名、工號、發生日期與時間 |
| 裝置與網路 | 使用哪一台裝置、當時在線或離線 |
| 功能與步驟 | 登入、巡檢、改善、紅牌或同步；做到哪一步 |
| 單號與區域 | 已顯示的巡檢、改善、盤點或紅牌單號 |
| 畫面證據 | 完整截圖與錯誤訊息 |
| 已做處理 | 是否已停止重按、待同步筆數與是否完成交接 |

> 異常回報只描述事實，不自行刪資料、不直接改試算表，也不用另一筆假資料沖銷。

## 十二、收班與交接

### 12.1 收班七步驟

1. 確認今日應巡區域已完成巡檢。
2. 記錄巡檢單號與所有低分項目。
3. 查看「改善」中的本人未結案件與驗證中案件。
4. 查看紅牌暫存品、處理中案件與到期風險。
5. 到「設定」執行「立即同步」，直到待同步 0。
6. 將未結案件、臨時控制與下一步交給接班者。
7. 公用裝置完成「登出」後再離開。

## 十三、一頁快速操作卡

### 13.1 主要作業路徑

| 我要做什麼 | 入口 | 主要按鈕 | 完成訊號 |
|---|---|---|---|
| 登入 | 登入頁 | 登入智慧 5S | 首頁顯示本人 |
| 巡檢 | 首頁或「巡檢」 | 立即開始巡檢、送出巡檢 | 巡檢單號 |
| 接改善 | 「改善」中的「我的」 | 開始改善 | 改善中 |
| 送改善驗證 | 改善案件詳情 | 完成並送驗 | 驗證中 |
| 新增盤點 | 「紅牌」 | ＋ 新增物品盤點 | 盤點編號 |
| 處理紅牌 | 紅牌案件詳情 | 開始處理 | 處理中 |
| 補送資料 | 「設定」 | 立即同步 | 待同步 0 |
| 更新資料 | 「設定」 | 清除快取並更新 | 以單號回讀一致 |

### 13.2 狀態速查

| 作業 | 原狀態 | 執行動作 | 新狀態 |
|---|---|---|---|
| 改善 | 待改善 | 開始改善 | 改善中 |
| 改善 | 改善中 | 完成並送驗 | 驗證中 |
| 改善 | 驗證中 | 管理角色驗證通過 | 已結案 |
| 改善 | 驗證中 | 管理角色駁回改善 | 改善中 |
| 紅牌 | 待處置 | 開始處理 | 處理中 |
| 紅牌 | 處理中 | 管理角色完成並結案 | 已結案 |

### 13.3 現場六句口訣

1. 先看本人：姓名與角色不對就停止。
2. 再選對區：站在現場核對區域與項目。
3. 逐項評分：5、3、1、0 依事實判定。
4. 異常留證：低於 5 分必填原因與照片。
5. 送出記單：只按一次，記單號與狀態。
6. 收班歸零：待同步 0，未結案件完整交接。

### 13.4 現場操作驗收

- [ ] 能以本人身分登入並核對角色。
- [ ] 能選對區域，完成一筆含低分異常的巡檢。
- [ ] 能寫出可定位的異常原因並拍合格照片。
- [ ] 能開始改善、填處理說明、拍改善後照片並送驗。
- [ ] 能新增非必要品盤點並說明紅牌實體管制。
- [ ] 能在離線後恢復網路，完成立即同步與回讀。
- [ ] 能用六要素回報異常，不重複送出或自行刪資料。
- [ ] 能完成收班檢查與公用裝置登出。
