# 製一｜智慧5S v1.3.6 驗收紀錄

日期：2026-08-26

版本：v1.3.6／1360

## 一、現場回報

機台履歷的「ISO巡檢存檔」卡片中，只有存檔索引、原始巡檢主單尚待手機回補的紀錄，右側按鈕顯示「待回補」且被停用，因此無法進入列印／儲存 PDF。

## 二、根因

ISO 模組為避免未完整資料被誤認為正式紀錄，原本直接將索引占位紀錄的按鈕設為 `disabled`。這同時隱藏了使用者需要的輸出入口，且與卡片上「可列印／儲存PDF」的說明不一致。

## 三、修復

- 待回補紀錄改為顯示可操作的「查看／列印（待回補）」按鈕。
- 可開啟既有 A4 ISO 巡檢表版面並使用 iPhone 列印／儲存 PDF。
- 沒有巡檢單號時不讀取其他空白明細，避免錯誤併入非本筆資料。
- 表內明確標示「原始巡檢主單尚待手機回補」及「不得視為完整稽核證據」。
- 未取得的分數與 25 項原始明細維持空白，不補造資料。
- 「立即同步待存檔」仍保留，完成回補後同一存檔會自動改用正式主單與明細列印。

## 四、自動驗收

Pages CI 會檢查兩個可能繪製機台履歷 ISO 卡片的模組都含有「查看／列印（待回補）」入口，並確認 A4 文件保留資料未完整警示，避免後續再次退版。

## 五、部署範圍

本版只修改 PWA 前端的 ISO 存檔檢視與列印入口，不變更巡檢、存檔編號、中央試算表或 Apps Script 寫入流程。
