## 四、導入進度六階段

每一主區域皆以以下六階段計算進度：

1. 區域盤點
2. 責任人確認
3. 標準照片完成
4. 現場張貼完成
5. 首次稽核
6. 穩定維持

完成率 = 已完成階段數 ÷ 6 × 100%。

B6、A9 已依會議現況建立初始進度；其他區域依 9/30 與 10/15 里程碑分波推進。

---

## 五、0–4 分稽核規則

- 4：完全符合標準
- 3：輕微偏差
- 2：明顯偏差，需要改善
- 1：嚴重不符合
- 0：無標準／完全失控

PWA 規則：

- 低於 4 分：必須輸入異常原因並拍照。
- 低於 4 分：自動建立 `5S_改善單`。
- 0 分或重大安全項目嚴重不符：視為重大異常。

---

## 六、動態稽核週期

- 新建區：7 天一次。
- 連續 3 次 ≥ 85 分：調整為 14 天一次。
- 連續 3 次 ≥ 90 分：調整為 30 天一次。
- 任一次 < 80 分：立即恢復 7 天一次。
- 重大異常：3 天內複查。

以上規則已同步寫入 `5S_系統參數`，並由 PWA 的 0–4 稽核流程回寫 `5S_稽核週期`。

## 八、LINE 提醒

新增：`gas/5S_動態稽核LINE提醒_v1.1.0.gs`

- 每日檢查 `5S_稽核週期`。
- 到期／逾期區域依 `5S_區域主檔.LINE群組識別碼` 推播。

- Token 只從 Script Properties `LINE_CHANNEL_ACCESS_TOKEN` 讀取，不寫入 Git 或試算表。
- 可建立每日 08:00 時間觸發器，也可傳入其他小時。

## 十、仍需外部平台完成的三個項目

### 1. Apps Script 正式部署

GitHub 已完成 GAS 原始碼，但目前連線工具無法直接把 Git 內容發佈成 Google Apps Script 正式部署。因此以下檔案需同步進正式 Apps Script 專案後重新部署：

- `gas/doGet_doPost_整合中央資料庫替換段_v1.gs`
- `gas/5S_動態稽核LINE提醒_v1.1.0.gs`

部署後執行一次：

`智慧5S_建立每日稽核提醒觸發器({ 小時: 8 })`

### 2. Google 試算表公開權限

目前 `⭐智慧工廠主資料庫` 的公開連結權限仍為「任何知道連結的人可編輯」。

正式環境應改為：**知道連結的任何人可檢視**，保留擁有者與必要管理人員的編輯權限。

現有連線工具只能新增分享權限，無法修改／刪除既有 `anyone/writer` 權限，因此此項不可在本次自動化連線中代替帳號所有者完成。

### 3. 助工責任區域圖來源

Drive 已搜尋 `Layout`、`責任區域`、`責任分佈圖`、`助工 責任區` 等關鍵字，目前未找到可明確辨識為會議所稱「助工責任區域圖」的檔案。取得該來源後，才能真正完成「責任區圖＋最新版 Layout」單一版本合併；在來源不明時不應自行猜圖。
