## 二、主鍵規則

### 全物品盤點

主鍵：`盤點編號`

格式：

`INV-001`、`INV-002` …

正式匯入判斷：

1. `盤點編號` 不可空白。
2. `物品名稱` 不可空白。
3. 只有預先編號但沒有物品名稱的列視為空白模板，不匯入。

### 紅牌追蹤

主鍵：`紅牌編號`

關聯鍵：`盤點編號`

例如：

`INV-012` → `RP-012`

禁止把 `INV-012` 寫入 `紅牌編號` 欄位。

## 七、後續區域導入標準

G2、G3 或其他製造區域上線時沿用本規則：

1. 先辨識有效盤點列。
2. 用 `盤點編號` 做增量更新，不用列號當主鍵。
3. 非必要品必須產生或關聯唯一 `紅牌編號`。
4. 必要性由非必要改回必要時，不刪歷史紅牌，改為 `作廢` 並留下原因。
5. 新位置先補 `5S_區域主檔`，再開放巡檢與排名。
6. 系統驗收測試資料一律保留，不與現場主鍵混用。
