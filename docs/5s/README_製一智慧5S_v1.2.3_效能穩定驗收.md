# 製一｜智慧5S v1.2.3 效能穩定驗收

更新日期：2026-08-23

## 本版已完成

1. PWA 入口版本統一為 `v=1230`，系統版本 `1.2.3`。
2. 底部導航固定 6 個核心入口：首頁、巡檢、改善、紅牌、可視化、設定。
3. 製一組、A5現況、A5稽核保留功能，但不再擠入底部導航；由首頁快速作業與功能中心進入。
4. 新增 `智慧5S_效能核心.js`：
   - 阻斷首頁模組對 `#頁面內容` 的自我觸發 MutationObserver 迴圈。
   - Google Sheets 前端讀取加入 20 秒記憶體快取與同請求去重。
   - 寫入後自動清除讀取快取。
5. `智慧5S_iPhone導航修復.js` 改為單頁即時切換；只有切頁失敗才使用 URL 備援，不再 220ms 後強制整頁重載。
6. `智慧5S_首頁精簡.js` 移除 `document.documentElement` 全頁 MutationObserver，改為有限次事件式排程，避免 iPhone 因任何 DOM 變動反覆喚醒。
7. GitHub Pages workflow 已加入語法驗證與回歸防護，禁止首頁精簡模組重新加入全頁 observer。
8. 中央試算表 `5S_系統參數` 已同步：系統版本 1.2.3、PWA入口版本 1230，並清除殘留 `v=1220` 說明。
