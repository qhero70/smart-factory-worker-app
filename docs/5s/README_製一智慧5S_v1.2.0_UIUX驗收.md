# 化新精密｜製一｜智慧5S v1.2.0 UI/UX 驗收紀錄

## 本版完成項目

1. 新工作階段強制回到工號登入，不再因 localStorage 舊使用者直接跳首頁；同分頁重新整理保留已驗證工作階段。
2. 新增響應式 UI/UX：手機底部抽屜表單、平板/桌機自適應欄數、44~48px 以上觸控目標。
3. 按鍵加入浮起、按壓、波紋與短暫等待動畫；支援 `prefers-reduced-motion`。
4. 卡片與長資料區段加入收合/展開；機台文字超長時預設精簡，避免首頁長距離滑動。
5. 新增物品盤點改為四步驟：區域 → 位置下拉 → 物品資料 → 使用頻率/必要性 → 照片與送出。
6. 位置不再完全自由輸入，提供機台/工位、操作面、工作台、工具、治具、檢具、文件板、投入/產出料框、在製品、踏台、地面、通道、紅牌暫存區等標準位置，仍保留「其他/自訂位置」。
7. PWA 品牌改為「製一｜智慧5S」，新增專屬 SVG 安裝圖示，入口版本統一 `v=1200`。
8. 新增 Roar 事件通知中心：CustomEvent `智慧5S:Roar`、浮動通知、未讀數、歷史、震動、網路與全螢幕狀態事件。
9. 新增 Fullscreen API：`requestFullscreen()`、`exitFullscreen()`、`document.fullscreenElement`、`fullscreenchange`，不支援時提示改用 PWA 獨立模式。
10. LINE 動態稽核提醒改為「區域摘要 + 最優先8項 + 其餘進PWA查看」，入口固定為 v1200，不再產生 v103 新訊息。
11. 紅牌列印標準明確定義為「A4 半張 = A5 148×210mm」，保留唯一掛牌序號與 QR 處置閉環。
12. GitHub Pages workflow 已加入登入防護、Roar、UIUX 模組語法檢查與 v1200/品牌檢查。
