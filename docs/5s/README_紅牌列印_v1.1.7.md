# 化新精密｜智慧5S 紅牌實體列印 v1.1.7

## 功能目的

紅牌案件建立完成後，可直接從智慧5S的「紅牌」頁面開啟案件詳情，列印 A5 直式實體紅牌，供現場吊掛或黏貼使用。

## 操作流程

1. 進入「紅牌」。
2. 新增物品盤點；必要性選「非必要」時，系統自動建立紅牌與改善單。
3. 點開該紅牌案件。
4. 在紅牌詳情底部點「列印／另存 PDF」。
5. 系統第一次列印會自動產生實體掛牌序號：`RP-YYYYMMDD-NNN`。
6. iPhone/iPad 可使用系統列印功能送至 AirPrint 印表機，或先另存 PDF。
7. 印出後可直接吊掛於物品、料框、設備或紅牌暫存區。

## 序號規則

- 格式：`RP-掛牌日期-每日流水號`。
- 例：`RP-20260822-001`。
- 同一張系統紅牌重印時，沿用第一次產生的實體掛牌序號。
- 每次列印均寫入 `5S_紅牌列印紀錄`，保留列印時間、列印人、版型與用途。

## A5 實體紅牌內容

- 實體掛牌序號
- 系統紅牌編號
- 物品名稱
- 規格型號
- 數量
- 掛牌日期
- 部門／區域
- 紅牌原因
- 暫存位置
- 處置建議
- 責任部門／責任人
- 預定處置日
- 案件狀態
- 盤點編號
- 掛牌人、責任人、複查／結案簽名欄
- 「處置完成並經核准前，不得移回原工作區」警語

## 驗收基準

- 紅牌詳情出現「列印／另存 PDF」按鈕。
- 第一次列印能取得唯一 `RP-YYYYMMDD-NNN` 序號。
- 重印同一紅牌不得更換序號。
- 列印紀錄可在中央試算表追溯。
- A5 版面可直接作為現場掛牌使用。

## 中央資料表

- `5S_紅牌追蹤`：紅牌案件主資料。
- `5S_紅牌列印紀錄`：實體序號及每次列印稽核軌跡。
