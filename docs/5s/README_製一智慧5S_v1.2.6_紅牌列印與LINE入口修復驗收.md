## 七、部署界線

GitHub main、PWA v1260、中央試算表參數與指令中心已更新。

但目前可用工具沒有 Apps Script 原始碼部署能力，Drive 也未提供可編輯的 `application/vnd.google-apps.script` 專案。因此：

- PWA 修復可由 GitHub Pages 發布。
- LINE Bot 新指令、每日訊息 v1260 與 Rich Menu 實體按鈕，必須在正式 Apps Script 同步／部署後才會影響實際 LINE。
- 在正式 GAS 尚未部署前，LINE 實機仍可能繼續發出舊 `v=103`，不得宣稱已在 LINE 正式環境修復。
