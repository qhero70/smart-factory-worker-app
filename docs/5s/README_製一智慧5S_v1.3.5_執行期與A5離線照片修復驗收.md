# 製一｜智慧5S v1.3.5 驗收紀錄

日期：2026-08-26

版本：v1.3.5／1350

## 一、本版目的

1. 修復正式入口在登入畫面載入期間出現的 JavaScript 語法與執行期錯誤。
2. 恢復 A5 現場 11 張正式照片，並確保 PWA 離線時仍可檢視。
3. 補強 GitHub Pages 部署前驗收，避免未列入舊版清單的 JavaScript 檔案再次帶錯部署。

## 二、根因與修復

- `智慧5S_A5照片內建資料_v1290.js` 的大型 Base64 內容曾被截斷，造成整支腳本無法解析；改為 11 筆短路徑索引，照片獨立存放為 JPEG。
- 5 支目前載入模組存在 `else初始化()`／`else綁定()` 黏字，瀏覽器會把它當成不存在的函式名稱；已改為正確的 `else 初始化()`／`else 綁定()`。
- 另修正尚未接入目前入口、但可能日後重新啟用的 `智慧5S_可視化標準管理.js` 同類問題。
- 原有 `SITE-A5-008.svg`～`010.svg` 截斷檔已換成有效相容包裝，避免歷史連結讀到破損 SVG。

## 三、A5 離線照片

- `SITE-A5-008`～`SITE-A5-018` 共 11 張照片皆已建立本機 JPEG 副本。
- 橫式照片限制為 960 × 720，直式照片限制為 540 × 720，兼顧手機清晰度與離線容量。
- Service Worker v1.3.5 會預先快取 11 張照片；畫面仍保留中央資料背景同步與 Drive 來源連結。
- JavaScript 不再內嵌大型 Base64，降低截斷、解析失敗與首次載入記憶體占用風險。

## 四、版本接線

- `智慧5S設定.js`：1.3.5／1350
- `index.html`：所有正式入口資源改為 `v=1350`
- `應用程式資訊.webmanifest`：PWA 入口、圖示與捷徑改為 `v=1350`
- `離線服務.js`：快取名稱升為 `化新精密-製一智慧5S-v1.3.5`

## 五、自動驗收

Pages CI 現在會：

1. 自動尋找並檢查 `docs/5s` 根目錄的全部 JavaScript，不再依賴人工維護檔名清單。
2. 驗證 Web App Manifest 為合法 JSON。
3. 阻擋已知截斷字串與黏字錯誤。
4. 驗證 1.3.5／1350 的入口接線。
5. 驗證 11 張 A5 JPEG 非空，且每張同時存在於照片索引與 Service Worker 快取清單。

## 六、驗收界線

本版為 PWA 前端、靜態照片與部署驗收修復，不需重新部署 Apps Script。涉及正式寫入的巡檢、ISO 存檔、紅牌與中央試算表資料流程未改動。
