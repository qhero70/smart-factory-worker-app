# 製一｜智慧5S v1.2.5 驗收紀錄

日期：2026-08-23

## 一、本版目的

1. 修正 iPhone Safari／PWA 頁首右上 Roar 鈴鐺圖示遭相鄰元件擠壓、裁切或覆蓋。
2. 建立 77 台機台共用的「機台5S電子履歷」入口。
3. 延續一機一檔：`MCHK-{區域}-{機台}`，不複製巡檢主資料。

## 二、鈴鐺顯示修復

- 頁首右側操作區改為固定尺寸、不允許 flex 壓縮。
- 全螢幕、Roar 鈴鐺、使用者頭像均固定觸控尺寸。
- Roar 鈴鐺與未讀紅點強制 `overflow: visible`，避免被通用 button `overflow:hidden` 裁切。
- iPhone 小螢幕時，連線狀態縮為狀態點，以釋放頁首寬度。
- 支援 `safe-area-inset-right`，避免瀏海／動態島裝置安全區造成擠壓。

## 三、機台5S電子履歷

新增：`智慧5S_機台履歷_v1250.js`

每個固定機台檔號可即時彙整：

- 最近巡檢得分與日期
- 巡檢累計次數
- 最近最多 10 次得分趨勢（85分基準）
- 20項明細的常發異常 TOP5
- 未結改善單
- 未結紅牌案件
- 5S照片證據數
- 主要負責人／代理人／主管／巡檢頻率
- 最近巡檢紀錄與巡檢單號

資料模型：

`MCHK固定檔號 → 巡檢主單 → 01～20明細 → 改善／紅牌／照片／責任區`

履歷採即時彙整，不新增第二份巡檢主檔，避免資料重複與版本失控。

## 四、現場操作

巡檢 → 選擇機台，例如 `MCHK-A7-1022` → `📚 查看5S履歷`。

「開始20項」仍維持正式 0–4 評分巡檢，不與履歷入口混用。

## 五、版本

- 系統版本：1.2.5
- PWA入口版本：1250
- iPhone頁首／導航修復：1.2.5
- Roar事件核心：1.2.4（事件功能不變，本版修正顯示排版）
- 機台巡檢核心：1.2.4

正式入口：`https://qhero70.github.io/smart-factory-worker-app/5s/?v=1250`
