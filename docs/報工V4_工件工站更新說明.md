# 報工作業 V4｜工件與工站改為 V2 版型

發布版本：541。依使用者上傳的「已貼上文字 (1).txt」之 V2 HTML 修改。

正式入口：[報工作業 V4](https://qhero70.github.io/smart-factory-worker-app/work-report-v4-477.html?v=541)。原 LINE 按鈕的同一 HTML 路徑仍可使用，不必修改 GAS 或選單。

## 本次調整

- 工件頁恢復大型「掃描產品條碼」按鈕、搜尋框、產品照片卡片。
- 照片使用 4:3，品名與編號在照片下方，不再壓在圖片上。
- 產品清單最高 400px，可捲動。與參考 HTML 相同：窄手機一欄、平板兩欄、桌面三欄。
- 選取產品後保留產品清單；下方顯示已選產品照片、產品編號與品名。
- 工站以「產品編號＋品名」對應原報工工站群組；保留原工序、產能、工時及機台物件。不再以另一份延遲規則覆蓋工站下拉選單。
- 選取產品後立即顯示工站、工序範圍、標準產能、標準工時秒、主機台欄位。未選工站時明細值留白。
- 切換產品或清空工站會清除先前機台與明細，避免沿用上一個工件。
- 保留機台照片與編號；可用主機台下拉選單或卡片選取。
- 相機辨識沿用參考版的瀏覽器原生條碼辨識方式；未支援或未授權相機時提供手動輸入及掃碼槍方式。關閉視窗、背景或離開頁面會停止相機。

## 保留項目

V4 的人員頁、產出、品質、不良分配、確認頁、原報工 API 與中央試算表不變。未修改 LINE 主路由、主管身分或智慧5S入口。

PWA 啟動版本與資源快取同步更新為 541，應用程式識別碼保留；只清理報工自己建立的快取，不清除智慧5S快取。

本次僅進行程式語法檢查及發布檔案回讀，未提交正式報工、未執行 LINE 或相機實機測試。
