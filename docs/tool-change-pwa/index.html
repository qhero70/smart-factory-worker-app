01系統總覽與適用對象System Overview & Intended Users

English — System Overview
This PWA is a guided tool-sheet generator for CNC lathe and milling operations. Instead of formatting Excel manually, the wizard asks for production and tooling information step by step and fills a print-ready A4 or A3 sheet automatically.
  • Type 1: A4 portrait for Lathe N/C, up to 8 displayed tool rows, chuck pressure, one QR Code, an A4 Tool Type dropdown, and 2480×3508 PNG export.
  • Type 2: A3 landscape for Milling M/C, 10+ tool rows, tool-image gallery, #500 settings, machine tips and two QR Codes.
  • Local autosave stores up to 10 sheets in this browser. Excel and JSON backup and PDF/print output are supported.

1-1 這套系統是什麼？

這是一套「對話式刀具表產生器」。傳統上，您必須打開 Excel、找到正確的範本、 一格一格輸入資料、調整欄寬、設定列印範圍，最後還常常因為格式跑掉而重做。

本系統把這整個流程反過來：由程式主動問您問題，您只要回答。 每回答一題，系統就即時把答案填進已經排版好的表格中。 等到所有問題回答完，一張可以直接列印的刀具表也就完成了。

1-2 適用對象

  • CNC 車床 / 銑床現場主管：需要快速產出換刀表交給作業員。
  • 製程 / 生技工程師：需要建立標準化的刀具清單文件。
  • 打樣 / 試作單位：臨時需要一份刀具配置表，但不想開 Excel。
  • 不熟悉 Excel 排版的人：只要會打字、會點按鈕就能完成。

1-3 支援的兩種表格格式

項目 第一類（A4 直式） 第二類（A3 橫式）
對應機型 車床 N/C 規格Lathe N/C Format 銑床 M/C 規格Milling M/C Format
紙張 A4 直式（210 × 297 mm） A3 橫式（420 × 297 mm）
刀具列數 固定 8 列（不足自動留空） 最少 10 列，可自動增加
刀具圖片 顯示於「刀具壽命」欄右側小圖 獨立 5 欄圖片牆，可放大量圖
特有欄位 夾頭壓力設定Chuck Pressure 貼心提醒 / #500 切換 / 機台技巧 / 雙品名Part Name

刀具數量多、需要放刀具照片牆、銑床加工 → 選 第二類 A3。

1-4 系統運作方式

  • 完全不需安裝：只要有瀏覽器就能開（建議 Chrome、Edge、Safari 最新版）。
  • 完全不需登入：沒有帳號、沒有密碼。
  • 本機自動暫存：平時資料存在這台裝置的瀏覽器（localStorage）；只有您主動按「儲存目前刀具表到 Google Drive」時，才會產生雲端備份檔。
  • 可離線使用：頁面載入完成後，即使斷網也能繼續操作與列印。
⚠️ 重要觀念：因為資料是存在「這台裝置的這個瀏覽器」裡， 所以換一台電腦、換一個瀏覽器、或清除瀏覽器資料，都會看不到原本的表格。 重要表格請務必列印或存成 PDFPrint or Save as PDF 備份。

02介面導覽（手機版 / 電腦版）Interface Guide (Mobile / Desktop)

English — Interface Guide
On mobile, use the bottom navigation for Guided Input, Preview, My Sheets and User Guide. On desktop, the conversation panel and live preview can be viewed side by side, and the dedicated Preview button opens a full-sheet view. Empty preview fields can be tapped and edited directly.

2-1 手機版（畫面寬度小於 768px）

手機版採用三個頁籤的切換方式，由畫面最下方的導航列控制：

頁籤 圖示 功能說明
對話輸入Guided Input 💬 與精靈對話、回答問題、建立刀具資料。這是主要的作業畫面。
預覽報表Preview 📄 查看已排版的表格。可直接點擊任何欄位編輯，也可按列印。
我的表格My Sheets 📁 管理本機暫存的刀具表（最多 10 張）。圖示右上角紅點會顯示目前張數。
💡 在手機上，預覽區會自動等比縮小以符合螢幕寬度， 讓您能一眼看到整張表的樣子。實際列印時會以 100% 原尺寸輸出，不用擔心縮放問題。

2-2 上方標題列

  • 🤖 精靈頭像（左側）：點擊可開啟頭像選擇視窗，更換成其他表情符號或上傳自己的圖片。
  • 📁 我的表格My Sheets按鈕（右側）：後方的數字（例：3/10）代表目前已暫存 3 張、上限 10 張。
  • ❓ 說明按鈕（右側）：隨時開啟本說明書，不會中斷您正在填寫的資料。

2-3 格式切換列

位於標題列下方，兩個按鈕：

  • 「車床N/C規格」：切換到第一類 A4 格式。
  • 「銑床M/C規格」：切換到第二類 A3 格式。

被選取的那一個會變成白底藍字。切換格式時，系統會：

  1. 先把目前正在編輯的表格自動存檔。
  2. 保留「製表日期」與「製表者」兩欄。
  3. 其餘欄位清空，並重新啟動對話流程。

2-4 對話區

  • 白色泡泡（左側）：精靈的提問或提示訊息。
  • 藍色泡泡（右側）：您剛才輸入的答案。
  • 每一則訊息都會有輕微的滑入動畫，新的訊息會自動捲到最下方。

2-5 底部輸入區

依照題目類型，會出現不同的輸入介面：

題型 出現的介面
文字題 文字輸入框 + 「發送」按鈕。電腦版按 Enter 也可以送出。
日期題 日期選擇器，預設帶入今天日期，可直接修改。
多行題 大文字框 + 「發送」+「套用預設」按鈕（可一鍵帶入建議內容）。
圖片題 「📸 選擇圖片或拍照」+「無圖，直接略過」兩個按鈕。
選填題 除了原本的輸入框，下方會多一顆「選填，略過此欄位」按鈕。
動作題 出現綠色大按鈕，例如「🚀 新增第一把刀具」。

2-6 電腦版（畫面寬度 768px 以上）

電腦版採左右分割畫面，不需要切換頁籤：

  • 左側（固定 440px）：對話面板，包含標題列、格式切換、對話歷史、輸入區。
  • 右側（自動填滿）：預覽面板，即時顯示排版結果。

也就是說，您在左邊打字，右邊立刻就會看到結果，邊填邊看，效率最高。 底部導航列在電腦版會自動隱藏。

03快速開始：三步驟完成第一張表Quick Start: Finish Your First Sheet in 3 Steps

English — Quick Start
  1. Select Type 1 A4 Lathe or Type 2 A3 Milling.
  2. Answer the wizard questions for basic data, tools, offsets, tool life, images and QR content.
  3. Open Preview, make any final edits, then print, save as PDF, export Excel/A4 PNG or create a Google Drive backup.

步驟一：選擇格式

在頂覽首頁按「🚀 開始製作刀具表
Start Tool Sheet」進入系統後， 先在上方切換列選擇 車床N/C規格 或 銑床M/C規格。 選錯了也沒關係，隨時可以重新切換，系統會重新開始引導。

步驟二：回答精靈的問題

精靈會從「基本資料」開始問起，一路問到「刀具資料」， 最後再問「QR Code 內容」。您只需要：

  1. 在輸入框打字。
  2. 按「發送」（或電腦上按 Enter）。
  3. 看到「選填，略過此欄位」時，若沒有資料就按下去跳過。
  4. 刀具資料會一把一把建立，每把填完都會問您「是否繼續新增」。

步驟三：預覽、微調、列印

所有問題回答完畢後，系統會顯示「🎉 恭喜！建立完成，已自動暫存」。 手機版會自動在約 1 秒後切換到「預覽報表Preview」頁籤。

在預覽區您可以：

  • 點擊任何文字欄位直接修改（詳見第 06 章）。
  • 點擊刀具圖片更換圖片。
  • 點擊 QR Code 修改內容。
  • 確認無誤後，按右上角「列印 / 存為 PDF」按鈕輸出。
✅ 整個過程最快大約 3 分鐘就能完成一張標準刀具表。 第二次之後，因為基本資料可以沿用，速度會更快。

04第一類 A4（車床 N/C）完整操作流程Type 1 A4 (Lathe N/C) Full Workflow

English — Type 1 A4 Lathe Workflow
Enter title, program/subtitle, date, prepared-by, chuck pressure, part name, Customer P/N, Product No., cycle time and daily quantity. For every N process, enter Tool Type, Tool No., H Offset, G Offset X, G Offset Z and Tool Life example: #534+1=30 Usage Count and TOOL LIFE (End Count)=30. Type 1 intentionally does not use a Tool Length column.

當您選擇「車床N/C規格」後，精靈會依序詢問以下欄位。標註「選填」者，可以直接按略過按鈕跳過。

07圖片上傳與自動壓縮機制Image Upload & Auto Compression

English — Images & Compression
Tool images can be selected during the wizard or replaced directly in Preview. Images are compressed automatically to reduce browser storage use while keeping sufficient quality for the tool-sheet layout. If local storage becomes full, delete unused saved sheets or reduce the number of images.

7-1 兩種上傳圖片的時機

  1. 對話過程中：精靈問到「請選擇導入圖示」時，按「📸 選擇圖片或拍照」上傳。
  2. 預覽區修改時：直接點擊表格中的圖片格子（或顯示「＋」的空格）即可上傳或更換。

7-2 自動壓縮機制（非常重要）

為了避免手機記憶體不足、也為了讓本機儲存空間夠用， 系統會在上傳圖片時自動進行壓縮處理：

處理項目 設定值
最大邊長 220 像素（等比例縮放，長邊不超過 220px）
輸出格式 JPEG
壓縮品質 0.7（兼顧清晰度與檔案大小）
背景處理 自動填白底（避免透明 PNG 變成黑底）
💡 建議的圖片來源：
· 手機直接拍攝刀具（近距離、光線充足）。
· 刀具型錄截圖。
· 白底或淺色底的圖片，列印效果最好。

7-3 更換圖片

在預覽區，只要再點一次已經有圖片的格子，就會跳出檔案選擇視窗， 選新圖後會直接覆蓋舊圖，不需要先刪除。

7-4 為什麼要壓縮？

  • 手機拍的原始照片動輒 3～8 MB，不壓縮會讓瀏覽器儲存空間瞬間爆掉。
  • 刀具表上的圖片只是示意，220px 已足夠列印出清晰的小圖。
  • 壓縮後每張圖約 10～25 KB，一張刀具表放 20 張圖也才 500 KB 左右。
⚠️ 如果上傳後跳出「本機儲存空間不足」的警告， 表示您的暫存表格太多了，請到「我的表格My Sheets」刪除不需要的舊表。

12常見問題 FAQ（20 問）FAQ (20 Questions)

English — FAQ
Common issues covered here include local-storage limits, missing images, print scaling, QR Code changes, loading saved sheets, switching A4/A3 formats, and using the PWA offline. If a sheet does not appear on another device, remember that local storage is device/browser specific; use JSON backup for transfer.
填到一半關掉網頁，資料會不見嗎？
不會。系統會在每一題回答後、每次欄位編輯後自動存檔。 重新打開網頁時，會自動載入您上次編輯的那一張表格。 但為了保險起見，重要表格仍建議存成 PDF。
為什麼我填了 10 把刀，列印出來只有 8 把？
第一類 A4 格式固定顯示 8 列，這是版面限制。 資料本身有被保存（在「我的表格My Sheets」可以看到刀具數量是 10）， 只是列印時只顯示前 8 把。超過 8 把請改用第二類 A3 格式。
選填欄位沒填，列印出來會是空白嗎？
是的，會是空白。空白欄位在畫面上會顯示淡灰色的「點擊輸入」提示， 但列印時這些提示不會印出來，所以是乾淨的空白格。
切換格式之後，原本填的資料去哪了？
切換格式前系統會自動存檔。 原本的表格會保留在「我的表格My Sheets」清單裡，您可以隨時載入回來。 只有「製表日期」與「製表者」會被帶到新格式中。
為什麼 QR Code 掃不出來？
請確認：
① 列印時有勾選「背景圖形」，否則 QR 會印不出來。
② QR Code 內容不要太長（建議 300 字元以內）。
③ 列印品質不要太差，建議 300dpi 以上。
④ 不要用「符合頁面大小」縮放列印。
圖片上傳後變模糊了？
這是正常的，系統會將圖片壓縮到最大邊長 220px 以節省空間。 刀具表上的圖片是示意用途，220px 印出來已經足夠清楚。 若需要更高解析度，建議另外附上原始照片。
可以在預覽區直接改資料嗎？
可以！這是本系統的核心功能。 點擊任何文字欄位就會進入編輯狀態，改完按 Enter 或點空白處即完成。 表格內容、圖片、QR Code 都能改。
為什麼我改了預覽區，對話區的紀錄沒有跟著變？
對話紀錄是「歷史紀錄」，記錄的是您當時的回答。 預覽區的修改會直接更新到最終資料，但不會改寫歷史訊息。 這是刻意設計的，避免歷史紀錄錯亂。
出現「本機儲存空間不足」怎麼辦？
表示瀏覽器能給的空間滿了。解決方式：
① 到「我的表格My Sheets」刪除不需要的舊表格。
② 減少刀具圖片數量（圖片最佔空間）。
③ 把重要表格存成 PDF 後刪除。
換電腦之後，我的表格My Sheets還在嗎？
不在。資料是存在原本那台裝置的瀏覽器裡， 不會跟著帳號同步。換裝置請事先把表格存成 PDF 帶過去。
可以用無痕模式操作嗎？
可以操作，但不建議。 無痕模式關閉視窗後資料會全部消失，無法保存。
列印出來字被切掉了？
請檢查列印設定：
① 邊界是否設為「無」。
② 縮放是否為 100%。
③ 紙張尺寸是否正確（A4 選 A4，A3 選 A3）。
④ 紙張方向是否正確（A3 需為橫向）。
可以同時編輯兩張表格嗎？
不行。系統一次只能編輯一張。 切換時會自動存檔，所以不用擔心資料遺失。 要同時處理兩張，建議開兩個瀏覽器分頁。
#500 的四行說明可以改成別的嗎？
可以。在對話中回答時直接輸入您的內容， 或在預覽區點擊該欄位直接修改。 若在對話中直接按「略過」，系統會套用預設的 L/R SIDE 說明。
「貼心提醒」和「機台操作小技巧」可以留空嗎？
可以留空，但系統會自動填入預設內容（刀長補正提醒 4 條、巨集指令 10 條）。 若您想留完全空白，請在對話中輸入一個空白字元， 或填寫後到預覽區把它刪光。
可以匯出成 Excel 檔嗎？
目前不支援直接匯出 Excel。 建議使用「列印 → 另存為 PDF」，或直接列印紙本。 若一定要 Excel，可將 PDF 匯入 Excel 做後續處理。
刀具圖片可以放幾張？
技術上沒有限制，但實務上建議：
· A4：最多 8 張（因為只有 8 列）。
· A3：建議 20 張以內（圖片牆會變太高，可能超出頁面）。
如果我不小心按到「重新填寫基本資料」怎麼辦？
系統在重新填寫前會先自動存檔，所以舊資料還在。 請到「我的表格My Sheets」找到剛才那張，重新載入即可。
為什麼 A3 的機台資料 QR 一直顯示 MACHINE-DATA？
因為您沒有設定「機台專屬」的 QR 內容。 系統會自動沿用主 QR Code 的內容；若主 QR 也是空的， 就會顯示預設字串 MACHINE-DATA。 點擊該 QR 圖案即可單獨設定。
這套系統需要網路嗎？
第一次開啟需要網路（載入字型與程式庫）。 載入完成後，即使斷網也能繼續操作、編輯、列印。 但建議還是保持連線以獲得最佳體驗。

13注意事項與資料保存Data Preservation & Important Notes

English — Data Preservation
Local autosave is convenient but browser data can be lost if site data is cleared, private browsing is used, the browser/device is changed or the operating system is reinstalled. Important sheets should be backed up as JSON and/or exported as Excel or PDF.

13-1 資料保存的黃金原則

⚠️ 本機暫存不是永久保存。
請養成「完成一張就存一份 PDF」的習慣， 這是最安全、最不會出錯的做法。

13-2 可能導致資料遺失的操作

  • 清除瀏覽器的「Cookie 與其他網站資料」。
  • 使用無痕 / 私密瀏覽模式。
  • 使用系統清理工具（如 CCleaner）清理瀏覽器資料。
  • 更換瀏覽器或裝置。
  • 作業系統更新或重設。

13-3 建議的作業流程

  1. 建立刀具表 → 完成所有欄位。
  2. 預覽區確認無誤。
  3. 立刻列印或存成 PDFPrint or Save as PDF。
  4. 存檔後，可依需求決定是否保留在本機暫存中。

13-4 列印品質建議

  • 建議使用雷射印表機，文字邊緣較銳利。
  • 解析度建議 300 dpi 以上，QR Code 才掃得順。
  • A3 表格務必使用 A3 紙張，不要用 A4 縮印。
  • 若需護貝或張貼現場，建議加印一份備份。

14快速鍵與效率小技巧Shortcuts & Productivity Tips

English — Productivity Tips
On desktop, press Enter to submit standard text inputs. Use Preview for quick corrections instead of restarting the wizard. Reuse an existing sheet as a template when the process is similar, then change part information and tool data as needed.

14-1 鍵盤快速鍵

按鍵 作用
Enter 在文字輸入框時送出答案；在預覽區單行欄位時完成編輯。
Esc 在預覽區編輯時，取消本次編輯並離開該欄位。
Tab 在預覽區可依序跳到下一個可編輯欄位（方便連續修改）。

14-2 效率小技巧

  1. 先準備好資料再開始：把刀序、刀號、H值、刀長先寫在紙上或記事本， 再來回答精靈問題，速度會快很多。
  2. 善用「選填，略過此欄位」：不重要的欄位不要卡住，先跳過， 之後在預覽區補填也可以。
  3. 多行欄位用「套用預設」：貼心提醒與機台技巧都有預設範本， 按一下就能帶入，再微調即可。
  4. 圖片先拍好：把所有刀具照片先拍好存在相簿， 填寫時連續上傳，不用中斷。
  5. 用「我的表格My Sheets」做範本：建立一張常用刀具表後， 載入它、修改品名Part Name客戶品號Customer P/N，就能快速產生新的一張。
  6. 電腦版左右分割最方便：左邊回答、右邊即時看結果，不用切來切去。
  7. 完成立刻存 PDF：這是保護心血最有效的方法。
  8. 善用預覽區直接編輯：填錯不用重跑流程，直接點該欄位改就好。
