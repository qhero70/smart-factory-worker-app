是否啟用語音引導？

開啟後，精靈會用語音把問題唸給您聽，
您也可以直接用麥克風說話回答問題，
並可說「發送」或「幫我送出」自動送出答案。

  • 🗣️ 語音朗讀：精靈每一題自動唸出，解放您的雙手。
  • 🎙️ 持續聆聽：麥克風持續開啟，不需反覆點擊。
  • 📤 語音送出：說「發送」「幫我送出」即可送出。
  • ⚙️ 自由調整：語速、音調、音量、語音角色可隨時修改。
  • 🔕 隨時關閉：不想聽時按語音按鈕即可暫停。
提示：語音功能需要您的瀏覽器支援 Web Speech API。

01系統總覽與適用對象

1-1 這套系統是什麼？

這是一套「對話式刀具表產生器」。傳統上，您必須打開 Excel、找到正確的範本、一格一格輸入資料、調整欄寬、設定列印範圍，最後還常常因為格式跑掉而重做。

本系統把這整個流程反過來：由程式主動問您問題，您只要回答。每回答一題，系統就即時把答案填進已經排版好的表格中。

本版本額外整合了 Three.js WebGL 電影級 3D 視覺：依 CAD 尺寸繪製的立銑刀 + BT40 刀柄、尺寸標註、PBR 物理材質、三點打光、PCFSoft 柔和陰影、ACES/Reinhard/Cineon 色調映射、雙指縮放。

1-2 適用對象

  • CNC 車床 / 銑床現場主管：需要快速產出換刀表交給作業員。
  • 製程 / 生技工程師：需要建立標準化的刀具清單文件。
  • 打樣 / 試作單位：臨時需要一份刀具配置表。
  • 不熟悉 Excel 排版的人：只要會打字、會點按鈕就能完成。
  • 雙手忙碌的操作員：可開啟語音引導，用聽的、用說的就能填表。

03快速開始：三步驟完成第一張表

步驟一：從首頁或側邊欄選擇格式

在功能首頁的「選擇刀具表格式」區塊中，點選 直式 A4 版型 或 橫式 A3 版型。

步驟二：回答精靈的問題（可選語音）

  1. 在輸入框打字，或按麥克風用說的。
  2. 按「發送」（或電腦上按 Enter，或說「發送」「幫我送出」）。
  3. 看到「選填，略過此欄位」時，若沒有資料就按下去跳過。

步驟三：預覽、微調、列印

  • 點擊任何文字欄位直接修改。
  • 點擊 QR Code 修改內容。
  • 按右上角 ⛶ 進入全螢幕檢視。
  • 確認無誤後，按「列印 / 存為 PDF」按鈕輸出。
  • 按「📊 Excel」匯出試算表。

06預覽區所見即所得編輯

預覽畫面上看到的每一個欄位，幾乎都可以直接點擊修改。

  1. 點擊要修改的文字。
  2. 欄位邊緣會出現藍色外框。
  3. 直接打字修改。
  4. 按 Enter 或點擊畫面其他空白處完成。
  5. 放棄修改按 Esc。

07QR Code 設定方法

  • 對話最後一題：精靈詢問。
  • 預覽區點擊 QR 圖案：跳出輸入視窗。

08我的刀具表與試算表儲存

📊 儲存原則：刀具表只以「試算表」格式保存——乾淨的列與欄，可匯出 Excel。
  • 本機最多 10 張。
  • 自動存於 localStorage 與 IndexedDB 雙重備份。
  • 正式 Google 試算表：建立完成後會同步寫入「刀具表_索引」「刀具表_明細」與「品名_OP」分頁。
  • 網頁版叫回：到「我的刀具表」選試算表分頁名稱，即可映射回 A4/A3 預覽並列印。
  • 跨裝置雲端同步：手機與電腦使用同一組同步碼，可合併同一批刀具表。
  • LINE 內建瀏覽器不能可靠選資料夾，但仍可使用雲端同步。

13常見問題 FAQ

填到一半關掉網頁，資料會不見嗎？
不會。系統會在每一題回答後、每次欄位編輯後自動存檔，而且是同時寫入 localStorage 與 IndexedDB 兩處。
為什麼我填了 10 把刀，列印出來只有 8 把？
第一類 A4 格式固定顯示 8 列。超過 8 把請改用第二類 A3 格式。
G 補正 X 軸或 Z 軸要填負數，怎麼輸入？
本版輸入框下方有「+ / −」輔助按鈕，點「−」即可切換為負值。
您也可以直接在輸入框打 -0.020 這樣的形式。
3D 模型跑不動怎麼辦？
把抗鋸齒設為 1x、陰影解析度設為 1024，或關閉環境粒子。
為什麼 QR Code 掃不出來？
請確認列印時有勾選「背景圖形」，內容不要太長，列印品質建議 300dpi 以上。
可以在預覽區直接改資料嗎？
可以！點擊任何文字欄位就會進入編輯狀態。
換電腦之後，我的表格還在嗎？
不在。請事先把表格匯出 Excel 或存成 PDF 帶過去。
列印出來字被切掉了？
請確認邊界設為「無」、縮放 100%、紙張尺寸與方向正確。
如何開啟語音引導？
第二排的 🔊 按鈕，或側邊欄「03 · 語音與音效」區塊的開關。開啟後會自動開始聆聽。
語音命令「發送」要怎麼用？
說「發送」「幫我送出」自動按下發送。
全螢幕按下去沒反應？
可能瀏覽器不支援 Fullscreen API，建議改用 Chrome、Edge 或最新版 Safari。
Excel 匯出時，圖片為什麼不見了？
Excel 單一儲存格有 32767 字元限制，base64 圖片會超過。系統會自動以文字替代，實際圖片請以列印 PDF 保存。
