## 重要：解除公開編輯權限

目前照片庫及其上層資料夾都顯示「知道連結的任何人可以編輯」。工件照片涉及公司製程資訊，不應採用此權限。

請用 qhero1982@gmail.com 開啟 Google Drive → 照片庫 → 管理存取權 → 將「任何人可編輯」改成「受限制」，並查核 A4.A3刀具表格式及相關上層是否仍繼承公開權限。

若上層資料夾有其他共享用途，不要直接改動整個共用庫；請管理員先把照片庫移到無公開共用的私有位置。照片後端會檢查各級父資料夾的存取權，未通過即拒絕自動上傳。

## 在原有 GAS 更新，不能另建第二個 Web App

需把 GitHub 這兩個檔案更新至「既有刀具表正式 GAS 專案」：

1. smart-factory-command-center/01_GAS後端/刀具表正式資料連線.gs
2. smart-factory-command-center/01_GAS後端/刀具表三視圖雲端照片.gs

兩個檔案只新增「刀具表_照片設定、照片上傳、照片查核、照片讀取」專用 API。舊有刀具表儲存、LINE、報工等路由不變。

GAS 必須由具有原專案編輯權限的管理員部署：部署 → 管理部署作業 → 編輯 → 選擇「新版本」，沿用原本的部署 ID 與 /exec 網址。

請注意：GitHub 程式碼提交完成不代表 GAS 已同步部署。亦不可為取得 GAS 存取權而把私人照片庫改成公開可編輯。

## 建立照片授權碼

使用 qhero1982@gmail.com 在 GAS 編輯器手動執行 **管理員_產生工件三視圖授權碼_**。此功能隨機建立 64 字元授權碼，只把 SHA-256 雜湊保留在 GAS Script Properties 中。

本次執行紀錄會顯示一次授權碼；請立即安全保存於密碼管理器，限制 GAS 編輯者權限。不得把授權碼寫入 GitHub、Google Sheets 或公開聊天。

## 使用流程

1. PWA 建立或載入刀具表 → 三視圖 → 拍照；手機 IndexedDB 保存原始 File，正式表單保留縮圖。
2. 三視圖視窗檢查照片雲端狀態，輸入管理員授權碼（僅本次有效）。
3. 點各視圖「🔒 自動上傳私有 Drive」；上傳完成後會再次以照片 ID 核對 Drive 檔案大小。
4. 新表或已載入表格在預覽按「💾 儲存目前刀具表至正式試算表」；需等原 GAS 寫入並讀回核對。
5. 另一裝置載入同一正式刀具表，查看三視圖縮圖，輸入授權碼後點照片，從 Drive 讀回高解析原圖。
6. 未取得雲端授權前，仍能用原有「分享原圖到雲端 → 貼入照片連結」手動備援，但不代表自動雲端寫入成功。

資料存放：Drive 保存高解析照片；本機 IndexedDB 保存拍照原始檔；正式試算表快照保存三視圖縮圖與雲端檔案 ID、名稱、容量及核對狀態，不直接寫入大圖 base64。
